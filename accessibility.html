Accessibility statement

Oilrun Mobile Mechanic & Auto Repair wants everyone, including people with disabilities, to be able to use oilrunflorida.com and request service from us.

Our goal

We aim to meet the Web Content Accessibility Guidelines (WCAG) 2.2, Level AA. We've designed the site to use semantic HTML, work with a keyboard and screen readers, use high-contrast colors, support zooming to 200% and narrow screens, and respect reduced-motion settings.

How we test

We check the site with automated accessibility tools and manual keyboard testing. Automated tools can't catch everything, so we welcome your feedback.

Need help or found a problem?

If any part of this website is hard to use, please tell us and we'll help you get service another way and work to fix the problem.
